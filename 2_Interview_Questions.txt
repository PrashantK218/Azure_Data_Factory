• You have 10 folders in ADLS. Each folder has multiple files. You want to process each folder through a databricks notebook activity.
How would you process all 10 folders in parallel?

1. Using ForEach Activity + Batch Count
In the pipeline parameter or trigger parameter pass the files names in an array. Pass this array to the ForEach Activity. Disable sequential execution.
Set batch count =10. Batch count depends on cluster configuration.

2. Handling Parallelism through DB Notebook:
Use ThreadPool / multiprocessing in notebook

3. Create Databricks Job with multiple tasks. Trigger from ADF. Databricks handles parallelism
