Pipeline parameters and variables:

pipeline parameters are external values passed into pipelines, datasets or linked services. The value cannot be changed inside a pipeline.

pipeline variables are internal values set inside a pipeline. The value can be changed inside the pipeline using Set Variable or 
append variable activity
